# FlyRank Assignment 1

This repository is the starting point for the FlyRank capstone project and its
AI-assisted development workflow.

## Stack

- Node.js 22 LTS
- TypeScript
- npm
- Git and GitHub

The application code will be added in later phases. This setup keeps the
toolchain and contribution conventions explicit from the beginning.

## Getting started

1. Install Node.js 22 LTS and Git.
2. Clone this repository.
3. Run `npm install` after the project manifest is added.
4. Run the project checks with the scripts documented by the application.

## Conventions

- Use Conventional Commits, for example `feat: add search endpoint`.
- Prefer TypeScript with strict type checking.
- Keep changes focused and update documentation when behavior changes.
- Add tests for new behavior and run the relevant checks before committing.
